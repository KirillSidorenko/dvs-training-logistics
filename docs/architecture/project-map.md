# Учебный плагин «Логистика»

Плагин используется в тестовом задании по поддержке AI-инструментов. В каталоге есть карточки отправлений, статусы и история движения, окна доставки, грузовые места, тарифы и реквизиты перевозчика. Для переноса в 1С плагин отдаёт поля из исходной карточки.

```mermaid
flowchart LR
    Codex["Codex"] -->|"MCP через stdio"| Server["server.mjs"]
    Server --> Tools["tools.mjs"]
    Tools --> Fixture["Вымышленные данные"]
```

В папке `plugins/dvs-training-logistics/` находятся манифесты, процесс MCP и определения команд. Сервер работает локально, не хранит учётные данные и не подключается к рабочим сервисам. Проверка и пробная загрузка не изменяют внешних данных.

Установка описана в [README](../../README.md). При изменении компонентов, интерфейсов или границ обновите эту карту.
